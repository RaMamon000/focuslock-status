# focuslock-status

iPhone の SNS Focus Lock アプリが読む「解除の札」だけを置く場所。

## 何が入っているか

`unlock/{日付}.{書き手}.json` という小さなファイルだけ。

```json
{
  "date": "2026-07-31",
  "source": "mac",
  "updated_at": "2026-07-31T02:05:00+09:00",
  "relock_hours": [0, 19],
  "conditions": {
    "finalize":      { "met_at": "2026-07-30T18:27:02+09:00" },
    "timebox_plan":  { "met_at": null, "count": 0, "required": 2 },
    "growth_weekly": { "met_at": "2026-07-29T14:11:42+09:00" }
  }
}
```

**日付と時刻と件数しか入らない。** 日報の中身・タスク名・画面の記録などは一切置かない。
それらは別の非公開リポジトリ（journal-sync）に置いてある。

この置き場を公開にしているのは、アプリが合鍵なしで読めるようにするため。
合鍵をアプリに持たせると期限切れで動かなくなるので、それを避けている。

## 書き手はファイルごとに1人だけ

| ファイル | 書く人 |
|---|---|
| `unlock/{日付}.mac.json` | Mac |
| `unlock/{日付}.cloud.json` | iPhone・クラウドの Claude Code |

同じファイルを2か所から書き換えないので、送信がぶつからない。
アプリは両方を読んで、**どちらかが条件を満たしていれば解除**する。

## 解除の判定

`relock_hours` に書いてある時刻（0時と19時）に、毎日自動でロックがかかる。
3つの条件のうち **どれか1つでも、直前のロック時刻より後に満たしていれば解除**。
どれも満たしていなければロックのまま。

| 条件 | 満たし方 |
|---|---|
| `finalize` | 日報をしめる（50文字以上） |
| `timebox_plan` | その日の見積もりを2件以上立てる |
| `growth_weekly` | 週次の振り返りを終える |

ファイルが取れなかったときは**ロックしたまま**にする（迷ったら閉める側に倒す）。

## 誰が書いているか

- Mac 側: `~/.claude/skills/progress-log/scripts/focuslock_status.py`
  （5分おきの裏ジョブから呼ばれる。中身が変わったときだけ送る）
- クラウド側: journal-sync の `instructions/finalize.md` の手順の中で書く

古い札は14日分だけ残して、それより前は消す。
